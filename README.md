المشروع الأول: موقع قصص الصحابة
1. فكرة المشروع
اسم المشروع: Sahaba Stories — قصص الصحابة
فكرة المشروع:
موقع ويب بسيط يهدف إلى عرض نبذة عن حياة بعض الصحابة الكرام رضي الله عنهم، مع توفير صفحات مستقلة تحتوي على معلومات وقصص عن كل صحابي.
المشروع من المشاريع التدريبية الأولى، والهدف الأساسي منه هو تطبيق أساسيات HTML وCSS بشكل عملي، والتدرب على تقسيم المشروع إلى مهام صغيرة وتنظيم الملفات والكود.

2. التقنيات المستخدمة
تم بناء المشروع باستخدام:
HTML
CSS
ولا يتم استخدام JavaScript أو أي مكتبات أو Frameworks في هذا المشروع.

3. أهداف المشروع
من خلال تنفيذ المشروع أهدف إلى التدريب على:
إنشاء صفحات HTML من الصفر.
فهم الهيكل الأساسي لصفحة HTML.
استخدام العناصر الدلالية مثل section.
تنظيم المحتوى باستخدام div.
إنشاء روابط بين صفحات الموقع.
ربط ملفات HTML بملف CSS خارجي.
تطبيق أساسيات CSS.
استخدام class لتنظيم واستهداف العناصر.
استخدام Flexbox لترتيب العناصر.
جعل التصميم مناسبًا لأحجام الشاشات المختلفة.
التدريب على تنظيم الكود واتباع مبادئ Clean Code بشكل مناسب لمستواي الحالي.

4. هيكل المشروع
المجلد الرئيسي للمشروع:
Sahaba-Stories
ويحتوي على صفحات الموقع وملف التنسيق.
الصفحة الرئيسية:
index.html
صفحات الصحابة:

5. تقسيم المشروع إلى مهام
تم تقسيم المشروع إلى مجموعة من المهام الصغيرة حتى يتم تنفيذ المشروع خطوة بخطوة، مع فهم وظيفة كل جزء بدلًا من كتابة المشروع كاملًا مرة واحدة.

✅ المهمة الأولى — إنشاء ملفات المشروع
الحالة: تم التنفيذ
المطلوب:
إنشاء مجلد باسم Sahaba-Stories.
إنشاء ملف index.html داخل المجلد.

✅ المهمة الثانية — إنشاء الهيكل الأساسي لصفحة HTML
الحالة: تم التنفيذ
المطلوب:
إنشاء الهيكل الأساسي لصفحة HTML، ويشمل:
html
head
title
body
الهدف من المهمة:
التدرب على إنشاء صفحة HTML صحيحة من البداية.

✅ المهمة الثالثة — إنشاء عنوان الموقع
الحالة: تم التنفيذ
المطلوب:
إضافة عنوان رئيسي للموقع باستخدام:
h1
العنوان:
قصص الصحابة
الهدف من المهمة:
التدرب على استخدام العناوين الرئيسية في HTML.

✅ المهمة الرابعة — إضافة وصف للموقع
الحالة: تم التنفيذ
المطلوب:
إضافة فقرة قصيرة أسفل عنوان الموقع توضّح فكرة الموقع.
مثال:
تعرف على قصص الصحابة الكرام رضوان الله عليهم.
العنصر المستخدم:
p

✅ المهمة الخامسة — إنشاء قسم الصحابة
الحالة: تم التنفيذ
المطلوب:
إنشاء قسم يحتوي على الصحابة الموجودين في الصفحة الرئيسية.
تم استخدام:
section
ويحتوي القسم على:
عنوان القسم.
كروت الصحابة.
اسم كل صحابي.
نبذة قصيرة عنه.
رابط لقراءة قصته.

✅ المهمة السادسة — إنشاء بطاقة أبي بكر الصديق
الحالة: تم التنفيذ
داخل div الخاص بأبي بكر الصديق تم إضافة:
اسم الصحابي باستخدام h3.
نبذة قصيرة باستخدام p.
رابط «اقرأ القصة» باستخدام a.

✅ المهمة السابعة — إنشاء بطاقات باقي الصحابة
الحالة: تم التنفيذ
تم إنشاء بطاقات مشابهة لكل من:
عمر بن الخطاب رضي الله عنه.
عثمان بن عفان رضي الله عنه.
علي بن أبي طالب رضي الله عنه.
وتم الحفاظ على نفس الهيكل لكل بطاقة لتسهيل تنظيم وتنسيق الكود.

✅ المهمة الثامنة — إنشاء صفحات مستقلة للصحابة
الحالة: تم التنفيذ
تم إنشاء صفحة مستقلة لكل صحابي.
كل صفحة تحتوي على:
عنوان الصحابي.
نسبه ومولده.
نشأته وحياته قبل الإسلام.
إسلامه.
صحبته للنبي ﷺ.
أبرز مواقفه.
خلافته.
أهم أعماله في الخلافة.
وفاته.
رابط للعودة إلى الصفحة الرئيسية.

✅ المهمة التاسعة — ربط صفحات الموقع
الحالة: تم التنفيذ
تم استخدام عنصر:
a
لربط الصفحة الرئيسية بصفحات الصحابة.
مثال:
<a href="abu-bakr.html">اقرأ القصة</a>
كما تمت إضافة رابط للعودة من صفحات الصحابة إلى:
index.html
الهدف:
التدرب على إنشاء روابط بين صفحات الموقع.

6. مرحلة CSS
بعد الانتهاء من هيكل HTML، بدأت مرحلة تنسيق الموقع باستخدام ملف CSS خارجي:
style.css

✅ المهمة العاشرة — ربط CSS بصفحات الموقع
الحالة: تم التنفيذ
تم ربط ملف CSS بالصفحات باستخدام:
<link rel="stylesheet" href="style.css">
وبذلك أصبح بالإمكان استخدام ملف CSS واحد لتنسيق أكثر من صفحة.

✅ المهمة الحادية عشرة — ضبط اتجاه الصفحة
الحالة: تم التنفيذ
تم استخدام:
direction: rtl;
حتى يكون اتجاه المحتوى مناسبًا للغة العربية.

✅ المهمة الثانية عشرة — تنسيق العناصر الأساسية
الحالة: تم التنفيذ
تم تنسيق:
h1
h2
h3
p
باستخدام خصائص مثل:
font-size
text-align
color

✅ المهمة الثالثة عشرة — تصميم كروت الصحابة
الحالة: تم التنفيذ
تم تنسيق كروت الصحابة باستخدام:
border
padding
margin
border-radius
background-color
box-shadow
width
وتم استخدام Selector أكثر تحديدًا:
.cards > div
حتى يتم تطبيق التنسيق على الكروت الموجودة داخل حاوية cards.

✅ المهمة الرابعة عشرة — تنسيق روابط قراءة القصص
الحالة: تم التنفيذ
تم تحويل روابط «اقرأ القصة» إلى شكل قريب من الأزرار باستخدام CSS.
تم استخدام:
background-color
color
padding
border-radius
display
text-decoration

✅ المهمة الخامسة عشرة — إضافة تأثير Hover
الحالة: تم التنفيذ
تم استخدام:
:hover
لتغيير شكل الرابط عند مرور مؤشر الماوس عليه.
الهدف من المهمة:
التدرب على التفاعل البسيط باستخدام CSS فقط.

✅ المهمة السادسة عشرة — استخدام Flexbox
الحالة: تم التنفيذ
تم استخدام:
display: flex
مع:
gap
justify-content
flex-wrap
وذلك لترتيب كروت الصحابة بشكل منظم والسماح لها بالانتقال إلى سطر جديد عند الحاجة.

✅ المهمة السابعة عشرة — استخدام Media Query
الحالة: تم التنفيذ
تم استخدام Media Query للتدرب على جعل التصميم مناسبًا للشاشات الصغيرة.
مثال:
@media (max-width: 767px)
والهدف هو تحسين شكل الموقع عند تصغير حجم الشاشة.

أثناء تنفيذ المشروع لم يكن الهدف كتابة أكبر عدد من الأكواد، وإنما فهم وظيفة كل جزء وتنفيذ المشروع تدريجيًا.
